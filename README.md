The restaurant name is "DENMARK RESTAURANT" which must printed in the front page of the website. The main theme is to provide authentic non vegetarian foods,  in chinese and arabian format in a state like Tamil nadu.  So add pictures according to this theme in the front page and give me nearly 100 buttons to add the dishes and its price.  In simple words I need a website which  contains the menu and can be ordered by the customers.  At the end of the ordering process it must contain 2options "DINE IN and DELIVERY" which notifies  that the cutomer is interested in dining or take away the order.
